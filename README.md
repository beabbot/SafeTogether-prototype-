# SafeTogether

SafeTogether is a women-focused platform designed to connect users with trusted companions for safer journeys home. The platform aims to improve community safety, confidence, and accessibility through technology-driven support.

## 🌟 Features
- Companion matching for safer travel
- Community safety support
- Prevention-oriented platform concept
- User-focused safety experience

## 🛠 Technologies Used
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## 🎯 Project Background
SafeTogether was developed as a student project focused on improving women's safety in potentially vulnerable situations. The project was successfully pitched in a university competition and received RM2,000 in project funding.
